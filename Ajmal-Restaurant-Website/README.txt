AJMAL RESTAURANT — COMPLETE WEBSITE
====================================

Open index.html in a browser or use VS Code Live Server.

Structure:
- index.html          Main website
- css/style.css       Complete responsive styling
- js/main.js          Menu, search, filters, cart and WhatsApp checkout
- images/restaurant/  Hero, interior and experience images
- images/food/        Featured food images
- images/menu/        Breakfast, lunch, dinner, salads, desserts, coffee, tea and juice images

Features:
- Professional restaurant landing page
- Responsive desktop/tablet/mobile layout
- Large menu with 42 items
- Menu category filters
- Menu search
- Shopping cart drawer
- Quantity controls and remove buttons
- Delivery / pickup checkout
- M-Pesa / cash selection
- WhatsApp order handoff using the Ajmal number configured in main.js
- Gallery and contact sections

This is a front-end website. Payment processing and a database/backend are not included.
